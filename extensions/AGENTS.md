# AGENTS.md

## Scope

Rules for the `extensions/` directory in this repository. These rules apply to the Pi TypeScript extensions stored here and do not replace the user's global `~/.pi/agent/AGENTS.md`.

## Inventory

Keep this table accurate when an extension is added, removed, renamed, or its user-visible behavior changes.

| File | Purpose |
| --- | --- |
| `auto-summary.ts` | Registers `/summary`: saves the latest text-bearing assistant reply without a model call (filename derived from the reply heading or session name); `/summary [instructions]` generates versioned Markdown from bounded branch context — the argument itself is the instruction text, there are no flags (`--generate` / `-g` do not exist). Generation is cancellable with Esc in TUI, blocks session/branch navigation until settled, and records valid provider usage even for failed/aborted replies before deciding whether to write a document. Summary entries include currency and outcome. |
| `powershell-bash.ts` | Replaces Pi's Windows shell execution (`bash`, `!` / `!!`) with validated PowerShell Core 7+ — Windows PowerShell 5.1 is unsupported. Checks the parsed AST for legacy targets, streams UTF-8 plain-text output, and makes cmdlet errors fail fast. Ordinary Windows descendants stay in a kill-on-close Job until exited; direct WSL AST calls use client-tree cleanup. Timeout defaults to 120 s; session shutdown joins active work. |
| `tps-status.ts` | Publishes the latest completed assistant response's decode TPS in TUI mode via `ctx.ui.setStatus("tps", ...)`. Measures from the first nonempty text/thinking delta or name/argument-bearing tool event to `message_end`, excluding TTFT and tool execution. Uses provider-reported `usage.output` only, with no character-count or `durationMs` fallback; live values are throttled to 400 ms and marked `~`. Aborted/error/deferred replies show no value. Clears stale state on session start, model switch and assistant start. |
| `anim-compaction.ts` | Compaction loading animation: `session_before_compact` (manual `/compact`, auto threshold, overflow recovery) shows an `aboveEditor` widget — rotating `-\|/` indicator + one of three animations + gold `X.Xs` + dim `· N msgs` (real pending-message count via `preparation.messagesToSummarize.length`), blue `· X.Xk tok` (`preparation.tokensBefore`) and a dim `· auto`/`· overflow` badge (`event.reason`, manual shows none); the widget does not repeat the built-in line's Auto-compacting/esc wording. Styles: `comet`/`a` 16-cell run-length-encoded comet bar, `wave`/`f` equalizer wave, `chase`/`g` 8-dot chasing trail; resolution `PI_COMET_STYLE` env > settings `cometCompactionStyle` > `random` (fresh pick per compaction), invalid values fall back to `random`. `/anim` opens a selection list marking the current entry with ✓ or accepts a direct style/alias; settings persistence preserves other keys, rejects malformed JSON, serializes writes with Pi's `withFileMutationQueue`, and replaces via same-directory temp file; env override warns. Palettes follow `ctx.ui.theme.appearance` (light uses darkened colors + mid-gray dim). 50 ms self-driven tick via `setInterval` + `requestRender`, monotonic elapsed time, ANSI-aware width clipping through Pi TUI's `truncateToWidth`; widget removal disposes its timer and `session_shutdown` is a cleanup fallback. TUI only, editor keeps Esc-to-cancel focus; built-in `Auto-compacting...` line untouched. |
| `notify-dot.ts` | Completion marker on the terminal tab title: `agent_settled` (not aborted) prefixes a single marker plus one BEL **only when the user is not on this tab** — `●` normally, `✅` when the run included a context compaction, `❌` when the turn errored (compacted or not). Compaction never shows on its own: it only swaps the done glyph at the next settle, and only compactions during the run count (a manual `/compact` between turns does not). Blocking UI prompts wait visibly too (`ui_prompt_start`: kind `confirm` → 🔐, other kinds → ❓, dropped on `ui_prompt_end`); unseen markers keep priority ❌ > 🔐 > ❓ > ✅ > ●. `notify-dot/presence-probe.ts` owns foreground-probe subprocesses, per-session caching, deduplication, and invalidation so stale child results cannot refill the cache. Presence: DECSET 1004 focus reports when the terminal delivers them (consumed across split input chunks, invisible to the TUI; reporting is enabled once per TUI lifecycle); otherwise `notify-dot/foreground-check.ps1` (async pwsh, 3 s cache, skipped outside Windows Terminal per `WT_SESSION`/`TERM_PROGRAM`) decides tab-level on Windows Terminal by window caption, then UIA selected tab matched on the ` - <session> - <cwd>` suffix, then a window-level ancestor check; input younger than 3 s skips the probe and an 8 s keypress heuristic is the last resort. The marker clears on any terminal input, `before_agent_start`, `session_start`, and `session_shutdown` — no polling or timers. Kill switch `PI_NOTIFY_DOT=off|0|false`; `PI_NOTIFY_DOT_PROBE=present\|away\|unknown` simulates the probe; debug log via `PI_NOTIFY_DOT_DEBUG=1`. |
| `ai-rename.ts` | `/n` renames the session (and the tab title): with an argument sets it directly; bare `/n` asks the session's own model for a short display name from a topic digest — every user message (whitespace-collapsed, 200-char cap, first 15 + last 15 past 30) plus the AI's first text reply (600-char cap), with slash-command invocations (including the triggering `/n` itself) filtered out — and cleans the answer (first line, quote/command-token/punctuation strip, 40-char surrogate-safe cap). Registered as `/n` because the builtin `/name` is dispatched by a hardcoded text match before extension commands and a colliding registration is skipped entirely. Mirrors auto-summary's model/auth/usage plumbing (`summary-usage` facts) and blocks session/branch navigation while a call is pending (re-running `/n` while pending notifies instead of starting a second call); aborted on `session_shutdown`. A named session also makes notify-dot's tab-title suffix unambiguous for same-directory sessions. |
| `permission-gate.ts` | Blocks credential file tools/searches and high-confidence shell access; shares snapshot authorization with `run-script`. Destructive commands confirm through a compact TUI overlay (`permission-gate/dialog.ts`, matching the finalized `gate-preview.ps1` style): severity-colored title (⛔高危/⚠中危 + Chinese rule label), ≤3-line command preview with the matched fragment inverted, merged target+consequence info line, horizontal option row (`[n]` block preselected / `[y]` once / `[a]` session-allow) navigable with ←/→ plus Enter-confirm and direct letter shortcuts; overlay closes via the completion callback on abort. `[a]` records the command sha256 in a session allowlist (later identical commands auto-pass with an audit-only decided entry; cleared on `session_start`); non-TUI dialog modes fall back to built-in confirm with Chinese label + consequence. Late approval after cancellation is ignored; asked/decided audit entries keep source hashes, never raw commands. Template `.env` files remain allowed; heuristic policy, not a sandbox. |
| `web-search.ts` | DeepSeek web search/fetch (`web-search/client.ts` API client + retry, `web-search/render.ts` theme-slot rendering). Tools: `web_search` (count 1–10, site:/quotes/|/../.. syntax in query; model content = numbered `[score/authority] title — site · ISO date` + ≤600c summaries + web_fetch hint; transcript box collapsed shows `1.7 ¶4` badges + relative dates + `↺ 同#N` mirror marks, ctrl+o expanded shows blocked layout with labeled `相关 x.xx/3 · 权威 x/4 · site · ISO（相对）` meta, success/warning/error score colors, authority ≥3 success, `┄` summary gutters) and `web_fetch` (URL validated http/https no-credentials; unescaped Markdown, 20k chars/page via `offset`, SPA/JSON limitations documented in the tool description). Both `readOnlyHint`+`openWorldHint`, `outputSchema`+`structuredContent` for codemode. `/websearch <query>` direct search overlay (TUI, no model round-trip; non-TUI notify), `/websearch fetch <n|url>` pulls the n-th result of the last direct search, `/websearch status` shows billed calls/cache hits/estimated cost. Client: 5 CNY per 1000 successful calls; 408/429/5xx exponential backoff×2, 402/4xx no-retry with friendly messages, session TTL cache (10 min, exact query+count) for free repeat hits, `PI_WEBSEARCH_DAILY_LIMIT` gate (default 300, 0=off), credentials resolve extension-folder `web-search/.env` (base_url/api_key) → pi auth.json `deepseek` api_key via readStoredCredential (exposed as `credentialSource`; key never in logs/details/errors; corrupt store/file tolerated). Empty results and failures not billed. |

Supporting modules are not extension entry points: `shared/usage.ts` provides usage/currency parsing for `auto-summary.ts`; `run-script/process.ts`, `run-script/powershell.ts`, `run-script/job-runner.ps1` and `run-script/job-runner.cs` implement the shared validated process owner (suspended-create/Job-assign/resume) used by `powershell-bash.ts`; `notify-dot/foreground-check.ps1` is spawned at runtime by `notify-dot.ts` for Windows Terminal foreground probing; `notify-dot/presence-probe.ts` owns foreground-probe process lifecycle and freshness; `anim-compaction/settings.ts` owns style parsing, Pi agent-directory resolution, and serialized/atomic settings persistence; `permission-gate/policy.ts` owns the heuristic policy and `permission-gate/dialog.ts` the confirmation overlay; `web-search/client.ts` and `web-search/render.ts` are imported by the `web-search.ts` entry point. Keep the relative layout when installing.

## Extension Rules

- Prefer the official Pi `ExtensionAPI`, `pi`, and `ctx` surfaces.
- Keep each extension focused on one user-visible behavior.
- Keep descriptions concrete: name the command, event, tool, environment variable, or visible result that is affected.
- Do not embed API keys, tokens, machine-specific absolute paths, or private service configuration in source files.
- Preserve UTF-8 text handling and Windows compatibility when changing `powershell-bash.ts`.
- Preserve versioned, non-overwriting Markdown writes when changing `auto-summary.ts`.
- Preserve provider-usage-only TPS calculation (no character-count or `durationMs` fallbacks) when changing `tps-status.ts`.
- Update this inventory and the root `README.md` when an extension's user-visible behavior changes.

## Validation

- Run the TypeScript check from an environment with Pi's type declarations installed.
- Reload Pi or restart it after installing or changing extensions.
- Manually verify `/summary` after changes to `auto-summary.ts`.
- Manually verify a normal shell command, timeout, and `PI_POWERSHELL_EXE` override after changes to `powershell-bash.ts`.
- Manually verify the `tps` status appears in the TUI after a completed reply, and shows no value for cancelled replies, after changes to `tps-status.ts`.
